# AWMS — Agricultural Warehouse Management System

```
AWMS/
  backend/            NestJS + Prisma + PostgreSQL API (see backend/README.md)
  admin-dashboard/    React (JS) web admin dashboard (see admin-dashboard/README.md)
  mobile/             React Native CLI (JavaScript) mobile app — admin + customer/staff
                       dashboards, Hindi/English, animated splash (see mobile/MOBILE_SETUP.md)
```

## Run both together (development)
```bash
cd AWMS/backend && cp .env.example .env && docker compose -f docker/docker-compose.yml up -d
npm install && npm run prisma:generate && npm run prisma:migrate && npm run prisma:seed && npm run start:dev
# in a second terminal
cd AWMS/admin-dashboard && cp .env.example .env && npm install && npm run dev
```

Admin dashboard on http://localhost:5173, backend API on http://localhost:3000/api/v1 (Swagger at `/api/v1/docs`). First login: `admin@awms.local` / the `SEED_ADMIN_PASSWORD` value from the backend `.env`.

## Run the full stack in Docker (production-style)
```bash
cp backend/.env.example backend/.env   # fill in real secrets — see backend/README.md
echo "POSTGRES_PASSWORD=change-me" > .env
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec backend npm run prisma:deploy
docker compose -f docker-compose.prod.yml exec backend npm run prisma:seed   # first run only
```
Admin dashboard served by nginx on http://localhost (port 80 by default, override with `FRONTEND_PORT`), which reverse-proxies `/api` to the backend container — no CORS configuration needed in this mode.

## CI/CD
`.github/workflows/ci.yml` lints, tests, and builds both packages on every push/PR (backend tests run against a real Postgres service container), and builds — but does not push — Docker images from `main`. Wire up a registry login + `docker push` step once you have a registry to push to.
